# Stock and Revenue Analysis: Tesla & GameStop

## Project Overview
This project analyzes historical stock prices and revenue data for Tesla (TSLA) and GameStop (GME). It was completed as part of the IBM Data Analyst learning project.

## Objectives
- Extract historical stock data using Yahoo Finance.
- Collect company revenue data using web scraping.
- Clean and organize data using Pandas.
- Visualize stock prices and revenue using graphs.
- Compare stock price trends with company revenue.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- yfinance
- Requests
- BeautifulSoup
- Matplotlib / Plotly (as used in the notebook)

## Project Tasks
1. Extract Tesla historical stock data.
2. Collect and clean Tesla revenue data.
3. Extract GameStop historical stock data.
4. Collect and clean GameStop revenue data.
5. Plot Tesla stock price and revenue.
6. Plot GameStop stock price and revenue.

## Files
- `Stock_Revenue_Analysis.ipynb` — Jupyter notebook containing the code, data analysis, and visualizations.

## Key Learning Outcomes
- Working with financial data using Python.
- Retrieving data from APIs and web pages.
- Cleaning tabular data.
- Creating visualizations to explore stock price and revenue trends.
